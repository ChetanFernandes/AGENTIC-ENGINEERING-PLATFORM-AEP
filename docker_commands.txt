# Build and start services
    docker compose up -d --build
            Part	                         Meaning in simple words
                docker compose	                  Manage the services defined in your docker-compose.yml file.
                up	                              Create and start the containers.
                -d	                              Run them in the background so your terminal is free.
                --build	                          Build or rebuild the images using your Dockerfiles before starting the services.

# docker exec -it aep-postgres-1 psql -U postgres -d postgres 
    a. -It targets the container directly by its name, aep-postgres-1, so it works even when you're outside the project directory.

# docker compose exec postgres psql -U postgres -d postgres
    a. docker compose exec postgres — targets the postgres service defined in your docker-compose.yml.
    b. psql -U postgres -d postgres — opens the PostgreSQL command-line client using the postgres user and connects to the default postgres database.
